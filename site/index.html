No phone number.
No ads. No tracking.

  • Encrypted on your phone. Messages and files are locked before they leave your device.
  • No analytics, ever. Vibe doesn't count, profile or sell anything.
  • Quiet notifications. They carry only a room and message ID, never your text.
  • Your account, your choice. It lives on the Matrix server you pick, not with us.

Checked before you install.
Every release, automatically.

  • Built in public. Every APK is built from the public source code by GitHub, not on someone's laptop. The build log is public too.
  • Scanned by about 70 antivirus engines. Each new APK is uploaded to VirusTotal automatically, and the result with a link to the full report is added to the release notes.
  • Same file, provably. The release notes list the APK's SHA-256 fingerprint. VirusTotal shows the fingerprint of the file it scanned; when they match, it's the file you download.
  • Only what's needed. No Firebase, no analytics, no notification access. Every server Vibe talks to is listed in the privacy policy, and every change in the changelog.
