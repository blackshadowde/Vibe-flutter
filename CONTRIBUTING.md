# Contributing to Vibe

Thanks for helping! Vibe is a Discord-style Matrix client written in Flutter.

- **Bugs and ideas:** open an issue with steps, screenshots and your phone model.
- **Code:** fork, branch from `Vibe`, keep changes small and focused, and open
  a pull request. Vibe's own code lives in `lib/vibe/`.
- **Checks:** the "Vibe check" workflow must pass (`flutter analyze`).
- **Licence:** contributions are under the AGPL-3.0, like the rest of Vibe.
  Keep the existing copyright headers.
